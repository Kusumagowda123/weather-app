WeatherNow 🌤️

A fast, clean, and interactive weather app built with React and Framer Motion, powered by the Open-Meteo API.

Get real-time weather updates, hourly forecasts, and animated weather icons in a beautifully designed interface.

Features

Search any city with auto-suggestions

View current weather with temperature, wind speed, and conditions

Animated weather icons based on weather codes

Hourly temperature chart for the next 24 hours

Smooth and responsive UI with animations (Framer Motion)

Tech Stack

React – UI library for building components

Framer Motion – Smooth animations

Open-Meteo API – Free weather data

Vite – Development server and build tool
